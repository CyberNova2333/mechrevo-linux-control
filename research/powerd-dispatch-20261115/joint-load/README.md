# 静音与高能的实际联合负载对照

证据状态：2026-11-15，原始 NVIDIA 595.99.02、6.8.0-149-generic，本机外置水冷离线运行。没有修改驱动、CPU拓扑、ACPI表或内核版本。固件的 LCSE 保持 0。

已验证 GPU 功耗联动有实际效果。使用同一份 CUDA 矩阵负载与 12 线程 CPU 矩阵负载，依次静音、高能、静音、高能，每阶段20秒。CPU负载未达到官方联合烤机判定条件，因此沿用已验证的 GAMM 游戏策略，没有强制 CTAF 联合烤机策略。用户选择静音/高能对应 APPE、TB43 与 PMSF；结束后撤销实验占用。

| 稳态样本（每阶段丢弃前2点） | 静音 | 高能 |
| --- | --- | --- |
| 样本数 | 16 | 16 |
| CPU包功率均值 | 59.984 W | 59.987 W |
| GPU实际功率均值 | 129.987 W | 139.836 W |
| CPU+GPU功率和 | 189.971 W | 199.823 W |
| 当前QBoost平台预算 | 190 W | 260 W |
| GPU单项最大值 | 140 W | 140 W |

高能的260W是总预算上限，本负载只消耗约200W；不能声称实测达到260W。GPU上限仍受140W限制。GDB只观察原驱动，捕获控制器实际请求130007/130017/130242/140000 mW，不改寄存器、函数返回值或功率命令。

全程 CPU 最高69°C、GPU最高61°C，温度停止阈值分别97/78°C。实验后 firmware status 的全部字段逐项相等；临时模块已卸载，GDB detach，所有实验负载退出，原 powerd 保持运行。`combined-load-summary.json` 由完整采样重新计算；脚本保留为研究证据，不是常驻运行入口。

这解决了此前“仅GPU负载两档均140W”的疑点：独立GPU测试不足以触及静音总预算。此处验证了功耗调度，不包括声压测量、所有游戏表现、AC拔插、整机休眠和水冷在线联动。
